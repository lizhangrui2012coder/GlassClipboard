# GlassClipboard
打开后自动记录复制的文字和图片。按 ⌥⌘V 呼出，搜索或用 ↑↓ 选择，回车复制，再到目标应用按 ⌘V 粘贴。支持置顶、代码高亮和 Markdown 预览；菜单栏可暂停记录或退出。使用cmd+option+v作为快捷键唤醒
剪贴板历史 1.0

打开 ClipboardHistory.app 后，菜单栏会出现剪贴板图标，点击显示历史窗口。
复制文字或图片后，新内容会自动进入历史。点击卡片或右侧复制按钮可重新复制，再到目标应用按 ⌘V 粘贴。
支持按内容、来源应用搜索；置顶记录优先显示并保留；普通记录最多保留 200 条。
“暂停记录”暂停收集，已有记录仍可使用；右键菜单栏图标可打开菜单、清空未置顶记录或退出。
按 Esc 或点击窗口关闭按钮可收起，退出请使用菜单中的“退出剪贴板历史”。

全部历史只保存在本机：~/Library/Application Support/GlassClipboard/history.json
没有联网功能。带有密码管理器保密或临时标记的剪贴板内容会跳过；没有这些标记的普通文本仍会记录。
目前支持纯文本和图片；复制回来时保留文本或图片，不保留富文本排版、文件列表。
启动前已有的剪贴板内容不会自动读取。单条文本上限 2 MB，PNG 图片上限 12 MB，超过大小跳过。

1.1 更新：参考 Frset 的剪贴板工作方式
- 左侧分类、中间历史列表、右侧完整预览。
- 自动区分文本、图片、链接、常见代码和十六进制颜色；JSON 可格式化预览。
- 单击选择，双击或回车复制并返回之前的应用；仍需在目标应用按 ⌘V 粘贴。
- 搜索框中按 ↑↓ 切换记录，Esc 收起。
- ⌥⌘V 在鼠标附近呼出；如快捷键注册失败，底部会显示被占用，请使用菜单栏入口。
- 历史数据沿用原版本。

1.2 更新：彩色代码预览
代码使用深色圆角背景、等宽字体和舒适行距；关键字、字符串、数字、函数、类型和注释分别着色。
预览标题可识别 C++、Swift、Python、JavaScript、JSON。着色仅改变显示，复制仍为原始内容。
超长内容前 120,000 个字符着色，其余继续完整显示；普通文本不使用代码配色。

1.3 更新：VS Code 2026 深色风格与 Markdown
- 已核对本机 VS Code 当前主题为“2026 深色”，代码预览采用对应近黑背景、Menlo 15 字号、字符串和函数配色及彩色括号。轻量语法识别不等同于 VS Code 的完整语言服务。
- 新增 Markdown 分类，支持标题、加粗、斜体、链接、列表、任务项、引用和围栏代码块。
- Markdown 可切换“预览／源码”，复制操作始终复制原始 Markdown 文本。
- 图片引用不会自动联网加载。
